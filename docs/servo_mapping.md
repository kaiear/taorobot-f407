# 舵机映射记录

## 底层接口

源码位置：

```text
firmware/SJRobot_center/Hardware_program/y_servo.c
```

核心接口：

```c
duoji_doing_set(index, aim, time);
```

## PWM 范围

源码限制：

```c
if (aim > 2490) aim = 2490;
else if (aim < 510) aim = 510;
```

因此舵机 PWM 范围大致为：

```text
510 ~ 2490 us
```

当前先回到原始软件 PWM 槽宽 `2500 us`，底座扩大范围也限制在 `510~2490` 内，避免 `400/2600` 对底层时序造成干扰。

## 特殊反向

源码中 `index == 3` 时做了反向：

```c
if(index == 3)
{
    aim = 3000 - aim;
}
```

机械臂调试时必须记录每一路舵机的实际方向、零位和安全范围。

## 调试变量

Keil Debug / Watch 中使用以下变量逐个测试：

| 变量名 | 作用 | 建议初值 | 说明 |
|---|---|---:|---|
| `servo_test_enable` | 开启测试入口 | `1` | `0` 时不会发送测试命令 |
| `servo_test_id` | 当前测试舵机 ID | `0` | 每次只测试一个 ID |
| `servo_test_pos` | 目标 PWM 位置 | `1500` | Debug 测试会走每个舵机独立限幅，改完位置后还要触发 `send` |
| `servo_test_time` | 动作时间 ms | `1500` | 首次测试建议慢一点 |
| `servo_test_send` | 单次发送触发 | `1` | 每发送一次会自动清回 `0` |

| 按键 | 动作 | 目标 PWM |
|---|---|---|
| `AR` | 回 Home | `1500,1500,2150,850,1500,1500` |
| `L2/R2` | 夹爪张开/夹紧 | `1200 / 1700` |
| `L1/R1` | 夹爪旋转约 90 度 | `850 / 2150` |
| `LU/LD` | 大臂前/后调试范围 | `800 / 1900` |
| `LL/LR` | 底座左/右调试范围 | `2490 / 510` |
| `RU/RD` | 小臂前弯/回收上抬测试 | `2350 / 1600` |

本轮修改目的：解决遥控器目标范围过小、部分按键两侧都在 Home 同侧、以及 AR Home 与上电 Home 不一致的问题。腕部 `ID3` 在底层有 `3000 - aim` 反向，若实际方向仍不符合预期，优先交换 `RL/RR` 或重新记录腕部两端值。

`START` 固定用于手柄保护/使能切换，`SELECT` 固定用于底盘速度档切换，不再分配机械臂动作。

## 单舵机测试流程

1. 舵机空载或拆掉连杆，只保留供电和信号线。
2. 设置 `servo_test_enable = 1`，`servo_test_time = 1500`。
3. 设置 `servo_test_pos = 1500`，从 `servo_test_id = 0` 开始测试。
4. 每次把 `servo_test_send = 1`，观察是否有某个舵机动作。
5. 找到 ID 后，固定该 ID，依次测试 `1450 -> 1500 -> 1550`。
6. 确认方向后，再逐步测试 `1400~1600`、`1200~1800`、`1000~2000`，最后在确认不会撞限位时才试探当前记录表内的真实安全边界。
7. 记录不会撞限位的最小值、最大值和推荐零位。
8. 所有单舵机记录完成后，再进行低速组合动作测试。
